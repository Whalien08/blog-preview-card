### What I learned

This project served as an excellent opportunity to solidify my frontend fundamentals, specifically focusing on clean HTML semantics and accurate CSS layout implementation. 

A major focus for this build was establishing a clean repository structure from the start to ensure seamless continuous deployment via GitHub Pages. I also prioritized accessibility by strictly adhering to proper semantic tags and ensuring robust `alt` descriptions for visual assets.

### Continued development

Moving forward, I aim to completely transition from fixed pixel units to relative units like `rem` for enhanced accessibility and scalability. I also plan to continue refining my use of Flexbox to handle responsive spacing effortlessly, reducing reliance on explicit height declarations or complex media queries.
